# 判词卡 P13：致癌突变是否降低 配体→ERK 信道容量（互信息实测）
日期：2026-09-28 状态：已判决
预注册：预注册卡_P13_信道容量互信息_2026-09-28.md（含修正案 A1）
数据：Gillies et al. 2020, Mol Syst Biol 16:e9518（PMC7569415，CC BY），Source Data Fig2
（等基因 MEF：KRASWT/HRASWT/NRASWT/KRAS-G12C/G12D/G12V/Q61R/BRAF-V600E，
EKAR3 FRET 单细胞轨迹，每条件 3 重复，约 400 细胞/条件）。
代码：p13_mutual_info_audit.py；结果存档：p13_mi_results.json。
口径：I(剂量档; 单细胞响应)，响应 = 刺激后 0–30 min 峰值 − 刺激前中位；
等频 8 分箱 + Miller-Madow 修正；细胞级 bootstrap 2000 次；ΔI = I_突变 − I_KRASWT。
判线（冻结）：|ΔI| > 0.2 bit 且配对 bootstrap 95%CI 不含 0 → 方向成立；±0.2 内或反转 → 不成立。
剂量档恰为 4 档（0/0.1/1/10 ng/ml），MI 上限 2 bit，所有数值应相对此上限阅读。

## 判决

**部分成立，且呈等位基因强度分级。**

1. 主检验 EGF：4 个 KRAS 突变中 3 个信道容量显著下降（G12C 恰过判线），G12V 不成立。
2. 跨配体一致性：突变等位强度（Q61R > G12D/G12C > G12V，生化上 GTP 酶缺陷程度同序）
   与信道容量损失同序。Q61R 与 BRAF-V600E 在全部 6 种配体下方向一致为负。
3. BRAF-V600E 的 EGF 信道几乎归零（0.013 bit）：细胞对 EGF 剂量完全失聪，
   这是"信道卡死"最极端的实测形态。
4. 与原文表述的关系：原文强调"动态范围被反馈重新标定保住响应性"（群体均值层面）；
   本卡在单细胞逐细胞层面实测互信息，发现即使均值响应存在，逐细胞的剂量分辨力已大幅下降。
   两者不矛盾，是群体均值与单细胞信息两个口径。本卡测的是后者。

## 对癌症链条总表的影响

"劫持而非中断"链条中的"信道卡死"环节从解读升级为实测：
强致癌等位（Q61R、BRAF-V600E）把 配体→ERK 信道容量压缩 0.3–0.4 bit
（相对上限 2 bit，压缩 17–21%；相对 WT 基线压缩 76–97%），
且在 6 种配体上方向一致。弱等位 G12V 不表现该表型，
提示信道压缩程度随突变生化强度分级，存在可检验的剂量关系。

## 遗留限制（登记）

1. 读出为 EKAR3 FRET 比率而非 KTR 核质比（修正案 A1 已登记降级）。
2. 剂量档 4 档，MI 上限 2 bit；分辨率有限，|ΔI| 的绝对值被档位上限压缩，
   真实容量损失可能被低估（方向性结论不受影响）。
3. MEF 等基因系，非人源肿瘤组织；外推到人体肿瘤需登记为推论。
4. 8 分箱选择固定于修正案，未做分箱数敏感性扫描（KSG 连续估计为候选复核口径）。

## 补记（2026-09-28 第二轮）：稳健性复核

分箱敏感性（4/6/8/12/16 档）：ΔI 几乎不变，Q61R −0.32 至 −0.34 bit，
BRAF −0.40 至 −0.42 bit，G12V 恒 ≈ −0.05 bit，判决不依赖分箱选择。
KSG 连续估计（k=4，细胞级 bootstrap 300 次）：G12C −0.18、G12D −0.23、
G12V −0.05（CI 含 0，维持不成立）、Q61R −0.31、BRAF −0.42 bit，
与分箱法排序、幅度、显著性完全一致。
**P13 判决对估计口径稳健。** 存档：p13_robustness.json；脚本：p13_robustness_recheck.py。
