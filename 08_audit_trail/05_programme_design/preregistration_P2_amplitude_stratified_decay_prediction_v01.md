## 1. 预言陈述（带符号方向与数值判定线，全部写死）

**背景机制**：数据天然携带三级规范固定——`_raw`（未校正）、AU（尺寸归一化浓度=规范固定）、`_molecules`（绝对丰度=未做尺寸归一化）；`cell_size_pixels` 为逐细胞增益代理。理论断言：**幅度型读出必须付费（归一化/校准）才可用，事件时间/计类型读出免费**。

**任务定义**：DM 系列（单脉冲）固定时长、相邻两幅度档（100↔275 nM、275↔690 nM、690 nM↔3 µM，≈25%/50%/75%/100% Msn2 激活）之间的逐细胞剂量判别，指标 = AUC（Mann–Whitney）。主分析时长 = 各启动子可用的最长 DM 时长（确定性规则：50 min 在则取之，否则取现有最长）；稳健臂 = 全部时长。

**三条预言 + 一条总证伪**：
- **P2-1（幅度付费）**：解码器 = 峰值 YFP_molecules。分层罚 Δ_mol ≡ AUC_混合 − mean(AUC_尺寸三分层内) ≥ **+0.03**（混合跨增益层**伤害**幅度解码器），在 ≥6/7 个野生型启动子上成立（突变体 pSIP18_mut6/mut21 只作描述）。
- **P2-2（归一化赎回）**：同一任务换用 AU（尺寸归一化）：Δ_AU ≤ **0.01** 且逐启动子 Δ_AU < Δ_mol——尺寸归一化=规范固定，应赎回幅度解码器。（若 Δ_AU ≈ Δ_mol，"归一化即规范固定"读法死亡。）
- **P2-3（事件时间免费）**：解码器 = 越阈时间（逐细胞基线 μ₀+kσ₀，基线取 t≤0 帧，k=3 主分析、k∈{2,4} 稳健臂）：|Δ_time| ≤ **0.01**——无分层罚。
- **P2-F（总证伪）**：P2-1 方向反或幅度不足 / P2-2 不成立 / P2-3 出现同量级分层罚，任一发生 → 对应条款记证伪，双录入账，**禁止事后修补口径**。

**次要臂（描述性，不进判定）**：FM/FM4 系列（脉冲数 8 vs 4）的计数解码表现；CFP 通道作普通增益探针的可行性（README 声明 CFP 信噪比差，预期弱）。

## 2. 分析管线锁定
1. **数据**：`2018_DataForPaper/{启动子}/{启动子}_DM_{时长}_{浓度}_size.mat`；变量：YFP/YFP_raw/YFP_molecules、cell_size_pixels、time、pulse_parameters、inhibitor_conc。
2. **细胞剔除（确定性规则）**：尺寸轨迹任意相邻帧相对跳变 > 40%（README 警示的分割错误）；校正后基线 YFP AU ≤ 0；轨迹缺失 > 10% 帧。
3. **分层**：逐细胞平均尺寸（时均）三分层；备择代理臂 = 基线 YFP_molecules 三分层。
4. **解码器**：幅度 = 响应窗（t∈[0, 152.5 min]）峰值 YFP_molecules（主）/AUC（备）；事件时间 = 首次越过 μ₀+3σ₀ 的时刻（未越阈= censored，计为非响应，另报响应率作计型解码器）。
5. **统计**：AUC 混合 vs 分层均值；Bootstrap 2000 次（逐细胞重抽样）给 CI；判定按预置边际（0.03/0.01），不按 p 值。
6. **多重性**：三档剂量对 × 7 启动子 = 21 个主判定单元；判定线按单元计，汇总按"≥6/7 启动子"计——均已写死，无需事后校正。
7. **实现**：单脚本（编号 代码44），用户机运行；随机种子固定；运行日志连同判定结果入总账。

## 4. 风险与诚实边界（登记）
1. **尺寸≈构造性混杂**：YFP_molecules = AU × 尺寸（绝对丰度由浓度乘回尺寸），故 P2-1/P2-2 部分地检验"尺寸归一化有用"这一近似已知事实；**预言的非平凡部分在解码器不对称性（P2-3 免费）与真实增益残差（基线 YFP 代理臂）**。已如实登记。
2. 输入侧逐细胞 MSN2_RFP 变异小（原文按确定性处理）——本预言只审输出侧解码，不审输入侧。
3. 数据为受控 TF 输入实验（1-NM-PP1），非天然刺激；天然刺激三签名（Hao & O'Shea 2012）无机器可读轨迹，列入 P3 尽调。
4. 同一数据集曾被原作者用于启动子解码研究（2013/2015/2021）；据我们多轮检索，**增益分层罚×解码器种类**的对比未被报告过——但"未见≠没有"（规矩③），投稿前需再检索一轮。
