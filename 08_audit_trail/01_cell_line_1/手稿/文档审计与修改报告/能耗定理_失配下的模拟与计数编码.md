# 失配下的能量-编码框架：何时模拟、何时计数

**定位：perspective 级组织框架（organizing framework），非定理——核心贡献为"增益硬顶/阈值软顶/计数免疫"不对称三件套；深度交叉为既有原理（von Neumann 再生、Sarpeshkar 精度交叉）在级联变量上的显式化增量。常数依赖建模假设，标度结构稳。**

**日期：2026-08-02 ｜ 状态：完整推导版 ｜ 定位：在 Sarpeshkar (1998) 的能量-精度权衡上推进三步——失配硬顶的形式化、深度交叉定理、计量学免校准概念的引入**

---

## 0. 问题与三误差源

一个信道要用相对误差为 $\varepsilon_0$ 的元件（静态失配：神经形态芯片 CV≈20% [^114^]；细胞蛋白表达变异 ~30%）可靠传输 $D$ 个可分辨水平。误差有三个来源，必须分开：

- **(T) 热噪声**：$kT$ 地板；模拟精度成本为**电容律** $E = kT/(2\varepsilon^2)$（每加 1 bit 能量 ×4 [^131^]）
- **(G) 增益失配**：静态、系统性的相对误差 $\varepsilon_0$——**不随时间平均，只能跨元件平均或校准**
- **(H) 阈值失配**：决策/触发阈值的静态偏移

---

## 1. 模拟振幅信道

**未校准容量硬顶。** 增益失配 $\varepsilon_0$ 是系统误差：输出 $S = \theta x$、$\delta\theta/\theta = \varepsilon_0$，可分辨水平被钉死在
$$D \le \frac{1}{\varepsilon_0} \qquad\Longrightarrow\qquad C_A \le \log_2\frac{1}{\varepsilon_0}\ \text{bits}$$
**这是硬顶：烧再多热噪声能量也打不破**（$\varepsilon_0 = 0.2 \to 2.35$ bit；$0.3 \to 1.80$ bit）。硬顶对失配值的敏感性：

| $\varepsilon_0$ | 0.05 | 0.1 | 0.2 | 0.3 | 0.5 |
|---|---|---|---|---|---|
| 硬顶 (bit) | 4.32 | 3.32 | 2.35 | 1.80 | 1.07 |

**截断与成本的分界（分段结构）。** $D \le 1/\varepsilon_0$ 时单元件即可，模拟能耗退化为电容律 $kTD^2/2$；$D > 1/\varepsilon_0$ 时进入冗余破顶区（下式）。**硬顶以下是"便宜"，以上是"更贵"，不是"死"——只要有冗余预算。**

**冗余平均破顶的能量。** 用 $M$ 个元件平均：失配项 $\varepsilon_0/\sqrt{M} \le 1/(2D)$ ⇒ $M = 4\varepsilon_0^2 D^2$；热噪声项 $\sigma_{th}/\sqrt{M} \le 1/(2D)$ ⇒ 每元件能量 $E_c = 2kTD^2/M$。最优分配下：
$$\boxed{E_A(D) = M \cdot E_c = 2kT\,D^2}$$
（$\varepsilon_0$ 在优化中消去；无失配时退化为电容律 $kTD^2/2$——失配的代价是 4 倍能量。）

**深度 $L$ 级联。** 各级误差独立时 $\varepsilon_{\text{tot}} = \sqrt{L}\,\varepsilon_1$ ⇒ 每级须达 $\varepsilon_1 = 1/(\sqrt{L}D)$ ⇒ 每级能量 $\propto LD^2$：
$$E_A(L, D) = 2kT\,L^2 D^2 \qquad(\text{相关误差最坏情形 } \propto L^3D^2)$$
——**模拟的能耗随深度二次（甚至三次）发散**（与 Hamerly 2022 光网络误差累积的实验观测一致 [^149^]）。

## 2. 计数信道

**单级能量。** $N$ 个全或无事件，Poisson 涨落 $\sqrt{N}$，可分辨水平 $\sqrt{N} = D$ ⇒ $N = D^2$。每事件的可靠性靠势垒：错误率 $\varepsilon_{ev} = e^{-\Delta G/kT}$ ⇒ 每事件 $\Delta G = \alpha kT$（$\alpha = \ln(1/\varepsilon_{ev}) \approx 7$ 对应 $10^{-3}$）：
$$E_B(D) = \alpha kT\,D^2$$
**与模拟同为 $D^2$ 标度，常数为 $\alpha$ vs 2**——单级下模拟反而便宜 $\alpha/2 \approx 3.5$ 倍（正是 Sarpeshkar "低精度模拟赢" [^145^]）。

**失配免疫结构（本定理的核心不对称）。**
- **增益失配 (G) 整个消去**：事件是全或无的，振幅失配不进入计数（dPCR 的 $\beta$ 消去、p53 的 $\alpha\to0$ 同款机制）；
- **阈值失配 (H) 被对数抑制**：$N = (\tau_r/T)\ln(D_0/D_c)$，$\delta D_c/D_c = \varepsilon_0$ ⇒
$$\frac{\delta N}{N} = \frac{\varepsilon_0}{\ln(D_0/D_c)}$$
——软顶 $C_B \le \log_2\!\big[\ln(D_0/D_c)/\varepsilon_0\big]$：$D_0/D_c = 100,\ \varepsilon_0 = 0.2$ → 23 水平 ≈ **4.5 bit**（vs 模拟硬顶 2.35 bit），且可拉伸 $D_0/D_c$ 继续提升。

**深度 $L$ 级联。** 计数在每级**再生**（全或无事件重新发出，误差不累积——von Neumann 再生论证 [^142^]）：
$$E_B(L, D) = \alpha kT\,L\,D^2$$

## 3. 深度交叉命题（既有原理的显式化，非新定理）

**"深度"的定义（关键）。** $L$ 不是级联长度，也不是再生次数（后者循环定义），而是**信息必须穿过噪声介质（扩散、稀释、重采样）的传输级数**：两级之间若共定位（支架蛋白复合体、膜结合模块），传输不经过噪声介质，深度不增加；若靠自由扩散交接，计一级。按此定义：支架化的 PdPC 模块 $L \approx 1$；自由扩散的激酶级联（RTK→Ras→MAPK，3–4 级）$L \approx 3$–4，**恰好坐在交叉点上**——与文献中 MAPK 级联输出极大的细胞间变异性自洽（坐在交叉点上意味着误差累积已经可观，这正是级联需要支架/反馈等误差控制结构的原因）。

$$\frac{E_A(L,D)}{E_B(L,D)} = \frac{2L}{\alpha} \qquad\Longrightarrow\qquad \boxed{L^* = \frac{\alpha}{2} \approx 3\text{–}4\ \text{级}}$$

（交叉公式在冗余破顶区计算；盖帽区 $D \le 1/\varepsilon_0$ 内模拟更便宜（$kTD^2/2$），$L^*$ 只会更大——即上式是保守估计。）

> **$L < L^*$（浅层）：模拟振幅编码能耗最优；$L > L^*$（深层）：数字计数编码能耗最优；与 $D$ 无关（$D^2$ 消去），交叉深度只由事件可靠性 $\alpha = \ln(1/\varepsilon_{ev})$ 决定。**

（最坏情形相关误差把交叉提前到 $L^* \approx \sqrt{\alpha} \approx 2.6$。常数依赖模型细节，但**"$L$ 决定编码制式"这个结构对标度律是稳的——但作为组织框架陈述，不作为编号定理**。）

## 4. 生物映射：四级证据链

| 层级 | 结构 | 深度 $L$ | 预言制式 | 实际观测 |
|---|---|---|---|---|
| 单级传感 | PdPC（树突局部处理） | 1–2 | 模拟、$\kappa^*$ 内点 | graded 响应 ✓（我们的 $\kappa^*$ 结果 = $L=1$ 极限） |
| 决策 | 卵母细胞开关 | 1（无后续） | 1-bit 开关（无需传输） | $n_H \ge 35$ 全或无 ✓ |
| 多级传输 | 轴突 | $10^2$–$10^3$（Ranvier 节） | 数字脉冲 + **每节再生** | 有髓轴突跳跃传导 = von Neumann 再生的生物实现 ✓ |
| 多级解码 | p53 → 下游多基因 | 多 | 数字计数 | 定幅脉冲、计数∝剂量 ✓ |
| 无校准测量 | dPCR | 1（但无外部参考） | 计数（自参考） | 唯一免校准平台 ✓ |
| 有校准测量 | ELISA | 1 + 外部标准品 | 模拟可行 | 校准曲线存在即可用 ✓ |

最后一行揭示了与 TCS 的回扣：**校准 = 让模拟在单级可行的外部参考；计数 = 自参考**。测量学（TCS）、细胞（p53）、神经（轴突）是同一个深度-参考结构的三张面孔。

## 5. 与先有工作的精确边界

| 已有 | 我们的增量 |
|---|---|
| Sarpeshkar 1998：模拟低精度赢、数字高精度赢 [^145^] | 给出**交叉变量是深度 $L$** 的显式定理 $L^* = \alpha/2$（其表述隐含精度变量，未含级联结构） |
| Vittoz/Murmann：模拟 1 bit = 4× 能量（电容律）[^131^] | 扩展为含失配最优分配的闭式 $E_A = 2kTD^2$ |
| Hamerly 2022：深网模拟误差累积（实验演示）[^149^] | 给出 $\sqrt{L}$/$L$ 复合的能耗发散律 $L^2D^2$（及最坏 $L^3D^2$） |
| von Neumann 再生（folklore）[^142^]、Lisman 1997 爆发脉冲可靠性 [^144^] | 形式化为三误差源分离 + 失配硬顶/对数软顶的不对称公式 |
| —（空缺） | **计量学免校准概念引入神经形态**：失配免疫可观测量 = 简并群不变量；模拟硬顶 $\log_2(1/\varepsilon_0)$ 是"不可校准"的容量表述 |

## 6. 诚实的局限

1. 常数（2 vs $\alpha$）依赖物理实现细节；定理的力量在**标度结构**（$L^2$ vs $L$、硬顶 vs 软顶），不在精确系数；
2. $\sqrt{L}$ 复合假设各级误差独立；相关误差加速交叉（$L^3$），不相关且可符号对消则推迟——真实系统居中；
3. 泊松计数假设事件独立；burst 结构/相关事件修改 $\sqrt{N}$ 指数；
4. $\alpha = \ln(1/\varepsilon_{ev})$ 是 Arrhenius 型势垒模型；亚阈值器件的实际事件能耗需按工艺修正（fJ–pJ 量级）。
5. 本定理说"制式选择"，不解决"如何训练"——学习规则的能耗是另一个问题（见愿景文档纪律条款）。
6. **本定理只比较单次信道使用的能耗，未比较速度/带宽。** 计数需累积 $N = D^2$ 个事件，带宽受事件速率限制；模拟每元件带宽丰富。故在高带宽浅层场景，模拟的优势比本定理给出的更大（Sarpeshkar 原文含速度维度 [^145^]）。生物例证自洽：视网膜感光细胞（高带宽、浅层）保持 graded 模拟信号，直到神经节细胞（需远距离传输）才转为脉冲——**速度与深度在视网膜前两级的选择方向一致**。

## 7. 一句话

**浅层模拟、深层计数，交叉在 $L^* = \alpha/2$；模拟被失配硬顶封喉（$\log_2(1/\varepsilon_0)$ bit），计数靠全或无事件消去增益失配、靠对数动态范围软化阈值失配——这就是"脑为何 20 W"在编码层面的定量回答，也是把 TCS 免校准原理接入能量计算的桥。**
